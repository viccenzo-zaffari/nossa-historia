Stack Recomendada

Tecnologias escolhidas para escalar com simplicidade

Frontend
Next.js 14 + TypeScript
SSR nativo, SEO para os álbuns públicos, e deploy simples na Vercel.
  • Tailwind CSS para estilo
  • Leaflet.js para o mapa
  • Framer Motion para animações
  • Spotify Embed API
Backend
FastAPI (Python)
API rápida, tipagem com Pydantic, e você já conhece Python.
  • SQLAlchemy + PostgreSQL
  • Alembic para migrations
  • JWT para autenticação do criador
  • Celery para tarefas assíncronas
Armazenamento
Cloudflare R2
Barato, sem egress fee, S3-compatível. Perfeito para fotos em escala.
  • Thumbnails automáticos
  • CDN global incluso
  • Custo previsível
Pagamentos & Deploy
Stripe + Railway
Stripe para assinatura e compra única. Railway para hospedar o backend com zero config.
  • Frontend: Vercel (free tier)
  • DB: Supabase PostgreSQL
  • Email: Resend
